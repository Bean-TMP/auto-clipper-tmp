# TruckersMP Auto Clipper

As the repo name suggests, this a **game plugin** for Euro Truck Simulator 2 and American Truck Simulator, specifically the modification [TruckersMP](https://truckersmp.com). It uses the in-game chat to detect when a ban has been issued by the local user and then using various recorders, records the last x seconds of gameplay to be used as evidence for said ban, without the tedious task of manually clipping every time. 

## Supported Recorders
- [OBS](https://obsproject.com/);
- ~~[Medal.tv](https://medal.tv/)~~ *(soon™)*

> The list of supported recorders is intentionally sparse as we can only support recorders that allow some form of programmatic interaction. If you know of any recorders that do just that, please open an issue.


## Storage 
All recorded clips using any of our supported recorders will end up in your [Medal](https://medal.tv/) video library, if configured that way.
